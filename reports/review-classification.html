  • Files 15 and 16: matching Khalid Al Nuaimi name variants and profile picture, with overlapping CV/LinkedIn feedback. Treat as a possible repeated customer, not two independent customers, until clarified.
  • File 3 is not the existing Maham testimonial: it identifies no customer and reports a Huawei Project Procurement Manager interview. The existing quote reports a first international Zoom interview. Do not join these stories.
  • File 6 is M Honey, not Mhassan Ali. No matching screenshot for the existing Mhassan attribution was identified in this archive.
  • File 10: Touheed Iqbal matches an existing name, but the supplied wording differs from the existing quote. Do not pair them as an exact source match. Use an accurate excerpt of the authenticated source after confirmation.
  • Files 1, 2 and 4: overlap with existing outcome or service themes. Do not display the image and the same testimonial as separate customers.
  • Generated material: the brief confirms some examples are generated but does not identify their filenames. All unverified material remains ineligible for publication as authentic; 9 through 30 require particular source clarification. Visual appearance alone is not a generation detector.
  • Missing proof: original Facebook post URLs or original captures, an explicit genuine/generated filename list, confirmation of WhatsApp source conversations and publication consent, and verified local evidence for each country.
  • Not supported: no supplied review explicitly establishes Arabic profile work, portfolio website delivery, Europass service or verified reviewer residence in the US/UK/Gulf. Do not create those claims.
  • Ratings: do not add five star ratings to Facebook recommendations or WhatsApp feedback. Preserve actual interface details, but do not convert recommendation text into a numerical rating or structured review schema.
